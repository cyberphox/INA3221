# Texas Instruments INA3221 Voltage Monitor Library
Arduino library for Texas Instruments INA3221 Triple Channel High-Side Measurement Shunt & Bus Voltage Monitor.

IC datasheet can be found at https://www.ti.com/product/INA3221 

Original project is from: https://github.com/beast-devices/Arduino-INA3221

A fork taken from  https://github.com/Tinyu-Zhao/INA3221
